# Auto Posto Florais — quinta a domingo e feriado (21,9 s)

`entrega/guerreiros-FLORAIS-QUI-A-DOM.mp4` — 1080×1920 · 30 fps · H.264 + AAC. `timeline.json` + `render.py`.

- Montagem: IMG_1885 (fala 1, 9,3 s) → corte com leve avanço (zoom 1,10→1,04) para NOVO_1885 (2ª tomada:
  "hoje é quinta, tem churrasco, um abraço" e ele vira para a churrasqueira) → dissolve de 0,3 s em IMG_1878
  (churrasqueira abrindo na fumaça até aparecer a carne) → fecho com logo + "AUTO POSTO FLORAIS" + dias.
- Legenda: texto enviado pelo cliente; tempo de cada frase pelo detector de voz (silero VAD) e das palavras por
  sílabas. Montserrat ExtraBold em blocos de 1 a 3 palavras, palavras-chave em degradê de brasa (GUERREIRO'S
  GRILL, AUTO POSTO FLORAIS, TEM CHURRASCO). Os dias viram pílulas que acendem quando ele fala cada um
  (vermelho da marca; FERIADO em dourado), encolhidas para caber entre as margens seguras (x 70–920).
- "Alto Posto" da transcrição escrito como "Auto Posto".
- Som: voz normalizada + trilha C (groove) a −22 dB com sidechain (abaixa quando ele fala).
