# Aviso de funcionamento no feriado (29,5 s)

- `entrega/guerreiros-FERIADO-30s.mp4` — 1080×1920 · 30 fps · H.264 + AAC · −13,6 LUFS (Reels/TikTok/Shorts).
- `entrega/guerreiros-FERIADO-30s-WHATSAPP.mp4` — mesma edição, ~10 MB (3 Mbps) para mandar aos clientes.
- Projeto: `projetos/feriado/timeline.json` + `render.py` (`--preview` para 540×960).

Materiais: 8 fotos (F1 peixe, F2 costela janela, F3 frangos, F4 picanha e frangos, F5 grelha de carnes,
F6 pernil com a lona @guerreirosgrill, F7/F8 costelas) + 3 vídeos (V1 grelha de costela girando na fumaça,
V2 frangos girando, V3 sal na costela — HDR HLG, convertido; a tela do CapCut do fim foi evitada) + trilha
enviada pelo cliente (92,3 BPM, batida 0,65 s; termina em ~29,4 s). Todos os cortes na batida.

Estrutura: 0–2,5 s gancho "AMANHÃ / TEM CHURRASCO!" · 3,8–11 s "ESTAREMOS / ABERTOS / NO FERIADO" (cedo, com
régua vermelha) · sequência de fotos com pan lento (fotos deitadas → mostra mais da foto) · 15,7–23 s "FERIADO É
DIA DE / CHURRASCO / AMANHÃ ESTAMOS ABERTOS" · 23,3 s fecho: logo + "VEM PRO / GUERREIRO'S GRILL / AMANHÃ ·
ABERTOS NO FERIADO". Anton + Montserrat, branco e degradê de brasa, sombra local; tudo dentro da área segura.
Sem horários, preços ou endereço (não fornecidos). Trilha vinda do TikTok: ok para WhatsApp; no Instagram pode
ser silenciada.
